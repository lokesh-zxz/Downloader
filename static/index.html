FFmpeg Setup Guide

Required to merge separate 4K video and audio tracks

YouTube and modern video platforms host 4K (2160p), 1440p, and 1080p video as a separate silent video track, and audio as a separate audio track. FFmpeg is the industry-standard media engine that yt-dlp uses to combine them into a single .mp4 file.

1-Click Install for Windows (Recommended):
winget install Gyan.FFmpeg

Open PowerShell or Command Prompt, paste the command above and press Enter. Once finished, restart this app and FFmpeg will be detected automatically!

Alternative: macOS / Linux brew install ffmpeg / sudo apt install ffmpeg
